# Daily Note

One note per day, in `Reflect Notes/daily/YYYY-MM-DD.md`. Sam's tasks and notes for the day go at the top. Eve adds a "Day overview" the night before and a "Daily recap" each evening, and carries unchecked tasks to the next day.
