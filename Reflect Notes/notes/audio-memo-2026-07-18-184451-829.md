# Stripping Back to Gmail API

Assistant: [[Ethan]]

[Recording](audio-memos/audio-memo-2026-07-18-184451-829.m4a)

Today I was a little discouraged with my email app that I'm rebuilding, but I'm realizing that I just need to strip it all the way back to just calling the Gmail API for everything, forget the sync and everything for now, and just get a good usable proof of concept going that I could use to start advertising and using to get a feel for it. And then down the road, I'll add the full inbox sync or full Gmail sync, see how large that makes the database and that kind of thing, and add the search functionality and caching and mutations and all of that down the road.
